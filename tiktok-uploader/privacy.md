# Oshio Short Uploader - Privacy Policy

Oshio Short Uploader is a private tool used only by its owner.

- Data accessed: the owner's TikTok open ID and display name (user.info.basic), and permission to upload videos as drafts (video.upload).
- Storage: the access token is stored only on the owner's own computer. It is not shared with anyone or sent to any other service.
- No data from any other TikTok user is collected.
- The owner can revoke access at any time in the TikTok app (Settings > Security > Manage app permissions).
